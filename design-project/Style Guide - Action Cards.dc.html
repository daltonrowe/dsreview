Vecteezy style guide

Action Cards

Action Cards appear inside an AI Magic bot response and summarize an action the user performed on the site. They sit flush under the bot message inside the grey response container.

Search Action Card

Shown when a chat query is submitted as a generic search (query appended with “(search)”). Text-only pill: orange search icon and the quoted query in bold — no images.

Generate Search Card

Shown when a chat query is submitted as a generation (query appended with “(generate)”). Sparkle icon, quoted query in bold, and four small preview thumbnails, in a card matching the chat-bubble radius.
